# PulseChat — Живой мессенджер на Flet 1.0 (без ИИ-ключей)

Мессенджер в стиле WhatsApp для общения всех посетителей сайта в реальном времени (через встроенный `page.pubsub` в Flet 1.0) + **Бот-Помощник** с заготовленными ответами.

## Возможности
- **Вход по имени и цвету аватара** — без регистрации.
- **Общий чат** — сообщения мгновенно приходят всем, кто открыл сайт.
- **Личные сообщения (1-на-1)** — нажмите на любого пользователя в блоке «Люди на сайте» слева.
- **Бот-Помощник** — заготовленные ответы и быстрые кнопки (`bot_engine.py`, легко добавить свои фразы).
- **Избранное** — личные заметки.

## Локальный запуск
```bash
pip install -r requirements.txt
flet run --web main.py
```
Откройте сайт в двух вкладках браузера под разными именами, чтобы проверить живую переписку.

## Обновление на Render (`Chat_bot`)
1. Замените файлы в репозитории `Chat_bot` на содержимое этого архива (старый `ai_service.py` можно удалить) и сделайте `git push`.
2. Никакие API-ключи в **Environment** на Render больше не нужны — сервис запустится автоматически.
